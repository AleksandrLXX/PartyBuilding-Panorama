# 本地运行与数据切换

## 环境要求

- Node.js 18 或更高版本
- pnpm 10（仓库锁定版本见 `package.json`）
- Chrome / Edge 最新稳定版

## 启动

```bash
pnpm install
pnpm dev
```

打开 Vite 输出的本地地址；默认显示首页。导航可切换五个栏目，底部可以暂停/继续自动轮播（默认间隔 30 秒）。首页、组织建设、党建工作为当前已实现页面；先进案例、群团工作是轮播占位页。

## 系统设置

点击右上角“设置”进入设置页，可设置自动轮播开关、5–3600 秒切换间隔、全局数据源以及可选的 API 服务地址。保存或恢复默认设置后立即生效并持久保存在当前浏览器；其他设备需要分别设置。停留设置页时自动轮播暂停，返回业务页面后重新计时；设置页不会被加入轮播。底部暂停/继续按钮同样会保存轮播开关。

数据源选择“本地 CSV”或“后端 API”时将覆盖旧的单数据集本地配置；选择“跟随环境配置”时仍保留单数据集配置，并以环境变量为默认值。API 服务地址只允许 HTTP(S) 域名和端口，留空时使用 `VITE_API_BASE_URL`，再回退到同源；不应填写账号、密码或密钥。API 接口和跨域策略由后端配置，设置页面不会验证接口是否可用。切换数据源后返回页面会重新读取数据；失败时显示错误，不静默回退。

## 屏幕适配

- 以 1920×1080 CSS 像素为设计基准；全局样式中的 `px` 通过 PostCSS 按 16px 基准转换为 `rem`，根字号随视口宽高在 16px～32px 间缩放。3840×2160 视口相对 1080p 放大两倍，同时兼容浏览器及 Windows 显示缩放。
- 普通电脑的矮屏视口保留可读字号，内容过高时可纵向滚动；窄屏会调整为纵向布局。建议大屏浏览器使用全屏、16:9 分辨率，并检查 Windows 缩放及浏览器缩放比例。
- 党建工作页中央地图的轮廓和单位点位仅作布局示意，不是真实行政边界或地理坐标。实际经纬度及地图数据确认后应替换，不可用于位置判断。

## 本地 CSV 数据维护

1. 将维护后的 UTF-8 CSV 放入 `data/raw`，文件名及表头严格遵循 [数据字典](../data/data-dictionary.md)。
2. 执行 `pnpm sync:data` 将 CSV 发布到 `public/data`。`pnpm build` 会自动同步；开发模式下如改了 CSV，执行同步后刷新浏览器。
3. 不要手工改 `public/data`；此目录是从 raw 生成的运行副本。原始填报 Excel 保留在 `data/raw/dangjiangongzuo.xlsx`。

## API 切换

可在设置页直接选择后端 API；也可复制 `.env.example` 为 `.env.local`，将 `VITE_DATA_SOURCE` 设为 `api` 并配置 `VITE_API_BASE_URL`，重启 Vite 后作为默认配置。后端需实现 `GET /api/dashboard/{dataset}`，响应字段及格式见 [数据字典](../data/data-dictionary.md)。选择“跟随环境配置”时，可在浏览器控制台设置 `localStorage.setItem('data_source_home_metrics', 'api')` 或 `'csv'` 覆盖单个数据集，清除该键恢复环境默认值。

## 构建与预览

```bash
pnpm build
pnpm preview
```

本项目使用 hash 路由；静态部署需保留 `public/data` 内容，并设置正确的 Vite `base`。生产构建会输出 bundle 体积提示，当前 Element Plus 在页面未使用时可考虑移除，减少首屏包体积。

## 常见问题

- 数据显示 404：确认 `public/data/{dataset}.csv` 存在，或先执行 `pnpm sync:data`；GitHub Pages 子路径由 `BASE_URL` 处理。
- CSV 中文乱码：统一将原始 CSV 保存为 UTF-8；读取端兼容常见 GBK/GB18030 编码。
- API 报错：确认环境变量已重启加载、接口返回非错误状态码、CORS/凭据策略符合部署方式。
- 党建工作页显示差异提示：这是原始 Excel 汇总与分类值的真实差异，核实之前不要改成推算值。
- 组织建设页出现“演示样例”：其数据为人工构造的占位样例，正式发布前必须替换为审核后的数据。
