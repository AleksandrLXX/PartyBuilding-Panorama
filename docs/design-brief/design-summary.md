# 党建全景屏设计概要

## 1. 项目目标

- 页面名称：党建数据分析平台（首页、组织建设、党建工作）。
- 业务目标：汇总呈现研究所党建组织建设与工作成效，支持大会/展厅大屏浏览。
- 目标用户：所内领导、党务工作者、党员及参观人员。
- 核心场景：横向 16:9 屏幕展示；五模块轮播，支持顶部直接切换。

## 2. 信息层级

- 头部：单位标识、党建平台标题、实时钟、五模块导航。
- 首页：核心数量卡片、组织生活趋势、武汉示意点位、片区组织明细及工作动态。
- 组织建设：关键指标、党委至基层组织结构、年龄/岗位结构切换、单位画像排行。
- 党建工作：源表汇总指标、单位明细、年龄段、在职岗位及支部类型分布。
- 底部：党建标语、轮播进度与暂停/继续、系统状态、数据来源说明。

## 3. 视觉规则

- 主色：暗红/朱红；辅助色：金黄、暖白；背景为暗红渐变和低对比网格光晕。
- 大屏基准：1920×1080，1366×768 可读；窄屏允许纵向滚动。
- 字体：系统中文黑体，数字使用等宽数字风格；避免必须联网加载字体。
- 图表：CSS/SVG 绘制条形图、环图、组织关系图和示意地图；不依赖外部图表服务。
- 动效：小范围呼吸灯、进度条、缓慢轨道动画；尊重 prefers-reduced-motion。

## 4. 交互规则

- 页面切换：顶部导航手动切换，底部进度点定位，30 秒自动轮播且可暂停。
- 筛选条件：组织建设页可切换年龄/岗位分布；当前无虚假下钻操作。
- 异常态：加载失败显示数据错误提示；源表合计不一致明确标注，不进行隐式修正。
- 空状态：缺数据时图表展示空列表/0；接口协议见数据字典。
