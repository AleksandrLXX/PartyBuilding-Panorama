# 大屏交互规则

## 页面级交互

- 首屏：默认加载首页，顶部显示实时本地时间。
- 页面切换：顶部五模块导航按钮手动切换；底部五个进度短线可直接定位页面。
- 自动轮播：默认开启，每 30 秒切换一个模块；“暂停轮播 / 继续轮播”可控制；用户手动切换后计时重新开始。定时器在壳层卸载时清除。
- 数据刷新：本版在进入模块时请求一次数据；若需周期性刷新，需等后端更新频率确认后统一配置。

## 模块级交互

- 组织建设：点击“年龄结构 / 岗位结构”切换党员结构图表，图例与环图同步。
- 其他数据卡片：当前为展示型，不进行筛选或下钻，避免无实际接口时产生虚假交互。
- 动效：轻量脉冲、轮廓旋转和进度条过渡；系统开启减少动态效果时停用非必要动画。

## 异常处理

- 数据加载失败：模块内展示错误内容和重新检查 CSV/API 配置的提示；不静默切换数据源。
- 字段缺失：可选展示字段保持空值或 0 作为占位；关键数据文件未找到时展示错误提示。接入正式 API 后需配合后端数据校验。
- 接口超时：沿用浏览器 fetch 默认超时行为；上线前应按后端 SLA 增加统一超时与重试策略。
- 无数据：图表退化为 0 或空列表；正式使用建议增加明确空状态文案。

## 验收标准

- 视觉一致性：沿用暗红底色、红金高光、细描边与统一标题层级；截图验收以 `design/exports/v1` 设计稿为基准。
- 交互一致性：五个路由可访问、导航指示正确、轮播可暂停/恢复、组织结构标签切换正常。
- 响应式表现：目标大屏 1920×1080，兼容 1366×768；窄屏可滚动查看而非压缩到不可读。
- 数据口径：党建工作页保留源表差异提示；组织建设页在正式数据替换前始终标示“演示样例”。
